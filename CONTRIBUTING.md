# Contributing

- **Add a link:** one line, in the right section, saying what it is and what makes it useful on a B70.
- **Known problems:** symptom as the user sees it (log line or error), cause/workaround as reported, and the upstream
  issue. Say "mitigation" when it only lowers the rate. Prefer the workaround someone measured over a guess.
- **Out of date?** Open an issue or PR with the source that shows it changed.
